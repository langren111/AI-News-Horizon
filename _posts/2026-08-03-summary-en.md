## [Kakehashi: Userspace Layer Runs macOS Binaries on Linux ARM](https://github.com/wie-project/kakehashi) ⭐️ 7.0/10

Kakehashi is an experimental userspace translation layer that runs macOS ARM64 CLI binaries natively on Linux aarch64, with working prototypes for 7-Zip, curl, and Git. It avoids kernel modules and JIT, using a lazy stubbing approach. This project addresses a significant gap in cross-platform compatibility, potentially enabling macOS CLI tools to run on Linux ARM without emulation. If successful, it could complement existing solutions like Darling and expand the ecosystem for ARM-based Linux users. Current prototypes show 7-Zip running ~5.2x slower than native Linux, with an optimization plan to reduce the gap. curl passes over 200 commands and options in automated Docker tests, and Git supports basic version control. The project is CLI-first and does not yet support GUI apps or codesign/notarization.

hackernews · vlad_kalinkin · Aug 2, 16:26 · [Discussion](https://news.ycombinator.com/item?id=49145937)

**Background**: Running macOS binaries on Linux has been a long-standing challenge, with Darling being the most notable translation layer, similar to Wine for Windows. Apple's Rosetta 2 allows Intel binaries to run on Apple Silicon, but there is no official way to run macOS binaries on Linux. Kakehashi takes a different approach by focusing on userspace and lazy stubbing, avoiding kernel modules and JIT compilation.
